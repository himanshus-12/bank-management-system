# Bank Management System

A simple command-line Bank Management System built using Python. This is my first beginner project in my coding journey, created to practise Python programming and understand how different concepts work together.

## Features

- Create a new bank account
- Generate a random account number
- Deposit money into an account
- Withdraw money from an account
- View account details
- Update existing account information
- Delete an account
- Store account information using JSON files

## Technologies Used

- Python
- JSON
- Random module
- String module
- Pathlib module

## Project Structure

```text
bank-management-system/
│
├── bank.py
├── README.md
└── data.json (generated locally)
```

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python bank.py
```

5. Follow the instructions displayed in the terminal.

## Python Concepts Used

- Classes and Objects
- Functions and Class Methods
- Lists and Dictionaries
- Loops and Conditional Statements
- File Handling
- JSON Data Storage
- Random Number Generation
- List Comprehensions

## How Data Is Stored

The project uses a JSON file named `data.json` to store account information. 
The program loads existing records when it starts and updates the JSON file whenever account information changes.

## Requiremnets
No external dependencies required.

## Disclaimer

This project was built for learning and practice purposes.
It is not a real banking application and should not be used for actual financial transactions.
Account information is stored locally, and PINs are not securely encrypted.

Built as my first hands-on Python project while learning programming.
A small project to practise core Python concepts and understand how they work together.
